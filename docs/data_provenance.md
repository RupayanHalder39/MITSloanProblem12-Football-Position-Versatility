# Data provenance

The private research workflow used an internal SoccerSolver export covering formation segments,
appearances, substitutions, and player-match statistics. The analysis corrected period-relative
clock resets before constructing the positional timeline and dominant-role dataset.

No redistribution licence was located for the source or row-level derivatives. They are therefore
excluded from this repository. Public artifacts are limited to the final paper, generated research
figures, aggregate frozen results, and code that demonstrates the published calculations.

The public release does not contain source videos, broadcast images, club photographs, tracking
frames, event coordinates, private correspondence, reviewer exports, database dumps, or local
machine paths.
